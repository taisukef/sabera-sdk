# Creating a GitHub PAT

[日本語](github-pat.md) | [English](github-pat_en.md)

The SDK is distributed through a private GitHub Packages repository. Create a GitHub Personal Access Token (classic) with
the `read:packages` scope, then configure it as described in [Getting Started](getting-started_en.md).

Keep the token private. Do not commit it to the repository or include it in application source code.
