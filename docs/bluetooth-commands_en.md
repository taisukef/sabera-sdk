# Bluetooth Commands

[日本語](bluetooth-commands.md) | [English](bluetooth-commands_en.md)

This section documents SABERA Bluetooth command IDs, packet formats, and the SDK APIs that use them.

See the individual command pages for the details of each packet:

- [Receive commands](bluetooth-commands/)
- [Transmit commands](bluetooth-commands/)

The packet format and byte order described here are part of the device protocol. Keep the command and firmware versions
in sync when implementing a lower-level client.
